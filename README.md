 # Quantum Capacity & Conserved Many-Worlds Lab
[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/YOUR-GITHUB-USERNAME/quantum-capacity-lab/main?urlpath=lab)

A computational physics exploration bridging theoretical quantum bounds (C_max) and hands-on simulation using Python, Qiskit, and RISE slideshows.

## Notebook Roadmap
- 01_superposition_and_vectors.ipynb: Superposition, probability amplitudes, and Ramsey fringes.
- 02_entanglement_and_entropy.ipynb: Bell states, density matrices, and von Neumann entropy.
- 03_quantum_eraser.ipynb: Branching, decoherence, and uncomputation.
- 04_cmax_capacity_simulation.ipynb: Non-linear collapse threshold testing.
